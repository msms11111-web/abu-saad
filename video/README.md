# فيديو دعم النادي الأهلي السعودي — نهائي كأس القارات ٢٠٢٦

فيديو تحفيزي عمودي (1080×1920 · 58 ثانية · 30 إطارًا/ث) يُبنى بالكامل من الشيفرة داخل هذا المجلد:
رسوم متحركة أصلية على `<canvas>` تُصوَّر إطارًا إطارًا بمتصفح Chromium، وشريط صوتي مُركّب رقميًا
(جمهور، طبول، صافرة، هتافات، موسيقى) مع تعليق مُولَّد بمحرّك النطق.

**الملف الناتج:** `ahli-support.mp4`

## الملفات

| الملف | الدور |
|------|-------|
| `scene.html` | المشاهد والرسوم: دالة `window.__seek(t)` ترسم لحظة محددة (يمكن فتحه في المتصفح لمعاينة حيّة) |
| `timeline.json` | الزمن المشترك بين الصورة والصوت (بداية كل مشهد، لحظات الأهداف والضربات) |
| `audio.py` | تركيب الشريط الصوتي بـ numpy + تعليق `espeak-ng` |
| `render.mjs` | تصوير الإطارات بـ Playwright ودمجها مع الصوت عبر ffmpeg |
| `preview.mjs` | لقطات ثابتة لمراجعة التصميم: `node preview.mjs 12.6 23.4` |
| `build.sh` | بناء كل شيء بأمر واحد |

## البناء

```bash
npm i playwright && npx playwright install chromium   # مرة واحدة
pip install numpy imageio-ffmpeg                       # مرة واحدة
./build.sh
```

الخطوط المستخدمة: **Cairo** و**Tajawal** (Google Fonts، رخصة OFL) — ثبّتها في النظام قبل التصوير
حتى تظهر الحروف العربية بشكلها الصحيح.

## تبديل صوت المعلّق

صوت المعلّق في النسخة الحالية **مُولَّد آليًا** بـ `espeak-ng` ثم يُعالَج (نطاق ترددي ضيق + تشبّع +
ارتداد الملعب) ليقترب من إحساس تعليق البث، لأن تعليقات البث الحقيقية ومقاطع المباريات محمية بحقوق النشر
ولا تُدرج هنا. للتبديل:

```bash
python3 audio.py --voice تعليقي.wav   # تعليق حقيقي مسجّل (يُمزج كما هو)
python3 audio.py --no-tts             # جمهور وطبول وموسيقى فقط بلا تعليق
node render.mjs --ffmpeg="$(python3 -c 'import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())')"
```

## تعديل المحتوى

- النصوص والأسماء والتواريخ: داخل دوال المشاهد في `scene.html` (`sIntro`, `sFinal2025`, `sMatch`, …).
- جُمل التحفيز: مصفوفة `HYPE` في `scene.html`.
- جُمل المعلّق: قائمة `LINES` في `audio.py` (تُكتب بالحركات ليصحّ النطق).
- توقيت المشاهد: `timeline.json` مع `var S` في `scene.html`.
